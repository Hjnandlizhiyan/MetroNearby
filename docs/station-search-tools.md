# 站名与线路工具

2026-09-25 用户确认：中文、拼音全拼、首字母、已有别名；无直接结果时给一处错字建议，明确“可能想找”，不自动选站。同名站显示城市及线路。

## 使用

首页搜索框、路线起终点、收藏常用目的地共用搜索：
- 古城 / gucheng / gc；支持大小写、拼音空格、声调和全角字母。
- 军博 / junbo 通过现有 aliases 找到军事博物馆，不新增未经核实的历史站名。
- fuxinmen 或 复新门显示“可能想找 · 请确认”的复兴门候选。
- 线路名称也可检索。选择器空输入列出所有可选站，使用懒列表，不截断到80项。
- 结果展示城市、线路与8dp线路色条；同城市换乘站合并，跨城市同名站分别列出。
- 首页手动选站、附近备选站和最近定位站携带城市限定键，进入详情和路线继续使用该键。
- 路线保留交换起终点、反向行程，并用独立色块突出换乘站及下一条线路。

## 搜索口径

StationLookup 为纯领域逻辑；StationChoice 聚合 aliases 和线路颜色。
缓存站点索引，输入变化不重新生成拼音表。
排序为当前站名精确、别名/拼音精确、前缀、包含、线路名称。
仅无直接命中时进行一次插入、删除或替换的建议；中文输入至少3字、拉丁字母至少4字，首字母不做模糊匹配。无后台请求，不自动跳转或改写查询。

StationPinyin 是由内置站名和已有 aliases 生成的847条检索键，不是官方英文译名。
自定义且不在索引中的站名仍可按中文和已存别名搜索；本版不承诺其自动拼音转换。
仅核对常见多音字（长椿街、长春桥、长阳、什刹海、十里堡等），不声称全部拼音经过官方逐站审核。
参考：https://bjsubway.com/en/station/fwss/line15/2013-08-26/258.html
核对日期：2026-09-25。已有历史别名的来源仍沿用原线路数据。

## 维护

tools/search-index/generate.py 使用开发工具 pypinyin 0.55.0 生成 Kotlin 表。
只在开发机运行，不打包 Python，不新增Android依赖；没有改动线路站序、坐标或时刻数据。
增加内置站点或 aliases 后需重跑生成脚本并审查多音字。
收藏本身沿用旧站名去重机制；跨城市同名站的独立收藏仍为后续迁移工作，不要把搜索城市隔离理解为收藏模型已迁移。
