# 北京线网补齐与城市标签

2026-09-19 将北京城市索引补齐到当前官网列出的 28 条线路。本次新增 11、12、15、16、17、18、19 号线，以及亦庄线、亦庄 T1 线、房山线、燕房线、S1 线、昌平线、西郊线、首都机场线和大兴机场线。

## 数据范围

- 站序、站名、站点坐标和两端全程车首末班边界取自北京地铁官网公开接口。
- 官网暂时给出零坐标的安贞桥、望京西，使用已复核的 OpenStreetMap 站点坐标兜底；望京西在 13、15、17 号线保持同一坐标。
- 相邻站运行时间按站距和线路类型估算，各站首末班由端点边界累计推算。
- 工作日与周末使用不同的分时段估算间隔；这些字段均保留 `needsReview=true`，界面继续明确显示“预计”。
- 官方接口原始响应缓存在 `tools/line-pipeline/out/`，可用 `Import-OfficialBeijingLines.py` 重建新增线路数据。

## 多城市准备

每个 `MetroLine` 增加可选的 `cityId` 与 `cityName`。当前 28 个北京线路文件都明确写入 `beijing` / `北京`，线路首页标题、设置页和线路选择器统一展示城市标签。旧的或测试线路不提供这两个字段仍能解析，以保持向前兼容。

后续接入其它城市时，应建立独立城市索引，在新线路 JSON 中写入对应城市字段，并由上层选择当前城市索引；线路卡片无需再为城市名称增加分支。
