# 地铁足迹基础版

## 已实现范围

- 首页当前站可“点亮本站”或撤销点亮；设置页和首页均可进入“我的地铁足迹”。
- 真实定位推荐的最近站同时满足直线距离不超过180米、定位精度不大于100米时自动点亮。
- 模拟位置、手动搜索选站、超出距离或精度不足都不会自动记录；这些情况仍可由用户手动补记。
- 每座物理站按城市和标准化站名保存一条记录，换乘线路共用同一条首次到访时间。
- 足迹总览显示所有已加载线路的点亮数、总站数、进度条和线路色；已点亮站按首次到访倒序展示。
- 基础徽章包括第一站、累计10站、累计50站和单线全部点亮。撤销站点后进度和徽章同步重算。
- 内置线路和自定义线路都参与统计。线路或站名数据变化后，历史足迹仍保留，并提示线路数据已变更。

## 数据与隐私

模型及判定在 domain/StationFootprints.kt，序列化在 data/FootprintCodec.kt，持久化在 data/source/FootprintStore.kt。

足迹保存到独立的 metro_footprints.xml，只记录：

- 城市限定的车站键、站名和城市名；
- 首次到访时间；
- 手动点亮或附近定位自动点亮的来源。

不保存经纬度、连续位置、路线轨迹和后续到访次数。该文件已排除 Android 云备份与设备迁移，避免足迹离开当前设备。读取损坏时禁止新增和撤销，防止空数据覆盖原记录。

自动点亮只在 App 获取一次前台定位并成功识别最近站后执行，不增加后台定位、常驻服务或新权限。首次记录写入后不因后续定位改变时间；用户撤销后，下次再次满足自动条件时可以重新点亮。

## 当前限制

- “到过”由近站定位阈值推断，不能证明用户已经进站乘车；首页明确允许撤销。
- 地下定位和站点中心坐标可能存在偏差，因此保留手动补记，不放宽自动阈值。
- 当前徽章为本机静态规则，没有账号、排行、联网同步或奖励系统。
- 本轮按用户要求只完成代码，不运行测试、不安装模拟器、不提交或上传 GitHub；等待用户自行测试。
