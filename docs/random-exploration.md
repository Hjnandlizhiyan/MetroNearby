# 随机探索

“随机探索”使用应用内现有的离线站点、足迹和路线数据，推荐一个尚未点亮且可达的车站。

## 推荐规则

- 起点由用户选择，默认使用首页当前展示的车站。
- 推荐范围只限起点所在城市，不跨城市规划。
- 所有已点亮足迹以及起点本身都会被排除。
- 可限制目标线路、5/10/20 公里直线距离，以及最多 0/1/2 次换乘。
- 距离是起点站中心到目标站中心的球面直线距离，不代表步行或乘车里程。
- 换乘次数来自现有离线路线规划，无法在静态线网中连通的车站不会作为结果。
- 再次随机会改变候选顺序，不读取网络，也不上传足迹。

## 使用入口

首页当前站卡片下方和设置页“地铁足迹”分组都可以进入。推荐后可直接把起点与目的地带入路线规划页。

## 数据与隐私

功能不新增持久化数据，不保存推荐历史，不使用后台定位。足迹仍只保存在本机的独立存储中。
