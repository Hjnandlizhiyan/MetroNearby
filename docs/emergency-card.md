## 入口与范围

- 首页站点概览下方“离线应急卡 · 位置与联系信息”。
- 设置中的独立“离线应急卡”入口，无定位权限也能查看已保存信息和服务热线。
- 最近定位来自 AndroidLocationProvider，手动搜索选站不会写入位置记录。
- 显示经纬度、采集时间、精度和模拟位置标记；超过现有2分钟有效窗口或异常时间时提示旧记录，不称为实时位置。
- 根据该定位点计算附近3站，保留线路色条，标明直线距离。
- 最近成功规划的路线保存一份静态文字快照及线路色，标明规划时间；失败规划不覆盖成功记录。
- 个人信息：联系人名称40字，电话号码选填（3至20位数字，可有国际区号+和显示分隔符），备注500字。
- 可分别清除个人信息和位置/路线快照，需要确认；不影响收藏或保存行程。后续成功定位/规划会重新记录最新快照。
- ACTION_DIAL 只打开系统拨号界面，无 CALL_PHONE 权限，不自动拨打。不读取通讯录、无后台任务、不发送短信、不自动分享。
- 打开官网来源会交由外部浏览器，需要网络；应用未增加 INTERNET 权限。

## 数据及维护

模型和校验：domain/EmergencyCard.kt；解析：data/EmergencyCodec.kt；持久化：data/source/EmergencyStore.kt。
独立 SharedPreferences 文件 emergency_card.xml，键 personal / location / route。
位置与路线只留各一份，不保存轨迹；旧时刻数据、收藏和用户线路不修改。
使用 commit 检查保存结果；读取损坏信息报错，不自动覆盖个人信息。各组独立读取。
应急卡文件已在 backup_rules.xml 和 data_extraction_rules.xml 排除云备份及设备迁移，不影响其他偏好的原备份规则。
