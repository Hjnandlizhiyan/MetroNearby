# 第一阶段：离线出行升级

## 已确认范围

- 地铁方向助手：从起点到终点，逐段显示线路、下一站方向、上车站、站数与换乘站。
- 附近站雷达：真北朝上，列出附近 8 个合并换乘站；按直线距离排序，编号对应图上点位。
  不随手机旋转，不声称提供步行导航。点击车站以该站为起点进入路线页。
- 通勤快捷模式：手动命名保存起终点和路线偏好，设为通勤后优先显示。可编辑名称/通勤标记、
  删除和反向规划。查看时使用当前线网重新规划；站点被删除时禁用查看和返程。
- 离线行程卡：路线结果可收藏，可通过系统分享面板分享 PNG。图片自动换行，包含全部换乘段、
  站数和离线说明。缓存目录通过 FileProvider 临时只读授权，不需要存储或网络权限。

## 入口

底栏：首页 / 收藏 / 路线 / 雷达 / 线网图。路线页规划后点击“收藏 / 设为通勤”或“分享图片”。
已保存行程位于“我的通勤与行程”，查看或返程后自动回到页首。
设置保留线路管理、自定义线路、外观、使用指引和未来规划。

## 兼容与清理

移除预计班次、校准、间隔学习、班次管理和区间车管理 UI；保留旧本地文件和兼容模型、领域测试。
自定义线路表单只需城市、名称、颜色、站序和坐标，不再要求首末班和间隔。
新行程单独保存在 metro_settings / saved_journeys，不覆盖原有收藏或时刻数据。

## 实现

- domain/TravelTools.kt：方位、雷达站点合并、行程校验、返程、方向文字与分享内容。
- data/source/JourneyCodec.kt / JourneyStore.kt：纯 JVM 编解码与 SharedPreferences 胶水。
- ui/RoutePlannerScreen.kt / StationRadarScreen.kt / JourneyShare.kt：界面与分享。
- 新规划操作在后台线程运行，避免主线程等待。
- 不新增第三方依赖，不移除 JaCoCo。
