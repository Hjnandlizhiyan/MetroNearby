# 自定义线路与城市分组

“我的线路”和底部线路选择器按 `cityName` 分组。城市组默认折叠，组标题显示城市、线路数量和当前置顶线路；展开后才显示该城市的各条线路。北京内置线与用户创建的北京线路会归在同一个“北京”组中。

## 创建与持久化

设置页“我的线路”提供“添加自定义线路”。用户填写：

- 城市、线路名称和 `#RRGGBB` 线路颜色；
- 至少两个站点，每行格式为 `站名,纬度,经度`；
- 基础首末班、发车间隔和相邻站运行分钟数。

`domain/CustomLineBuilder.kt` 负责纯逻辑校验并生成稳定线路 id、站点 id、双方向全程车、工作日/周末服务和相邻线段。自定义线路序列化后保存在 `metro_settings.xml` 的 `custom_lines` 字段，内置 assets 始终只读。

自定义线路会和内置线路一样参与附近站检测、站点搜索、订阅、区间车和用户校准。删除线路时同步移除其失效订阅；历史修正仍保留在 `user_overrides.json`，避免误删用户观测。

## 班次修改

创建后的基础时间只用于产生可工作的初始班次。用户可进入“班次表管理”，分别选择双方向和工作日/周末：

- 修改总班次数；
- 增加、删除或修改逐趟发车；
- 修改同一趟车的沿途站时间；
- 使用既有的倒置与超车检查。

因此自定义线路不维护第二套班次模型，仍遵循 `serviceTrips` 高于基础间隔的现有优先级。
