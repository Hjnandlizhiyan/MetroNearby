# 到站预测改进记录

## 本轮范围（2026-09-18）

用户选择：保持离线，先修正推算错误、核对官方数据。后续新增主界面口径选择，用户可在系统预计与用户校准之间切换。

已修正：

- 间隔推算跨过配置末班时，补上明确配置的末班，避免提前收车；恰好命中时不重复添加。
- 本站精确时刻序列优先使用，不再依赖是否具备发车间隔、站间时长；精确时刻去重，仅在同一站同一交路内去重。
- 环线上的区间车仍须在自己的终点清客，不再沿用环线全程车的终点例外。
- 非正发车间隔视为无效数据，不生成班次。

首末班标签仍按交路的最终班次序列判定。用户观测平均方式、停站窗口和不同交路之间不去重的口径不变。

没有直接拿各站首班相减替换全部运行时长：官网反向首班在东管头为 06:00，下一站西局却为 05:45，说明这些首班不是同一列车。当前模型只有线性全程交路，直接套用会把分段出库误当成负运行时间。

## 后续优先级

1. 支持逐站首末班运营边界与分段出库，区分“本站首班”与“同一列车的运行偏移”；需要先明确模型口径，再补齐官方逐站数据。
2. 支持跨零点的运营日：数据可写 24:xx，但当前界面午夜后按新一天查询，尚不能接续前一运营日末班。调整时间口径时必须补跨工作日/周末测试。
3. 核对车站可乘状态。当前 OSM 数据中含红庙，但本次[官方运营站表](https://www.mtr.bj.cn/service/line/line-14.html)与时刻表没有该站；[北京市 2026 年建设计划](https://www.beijing.gov.cn/ywdt/gzdt/202602/t20260203_4486799.html)将其列为推动具备开通条件的站。尚未取得当前已开通的公告，不将“在 OSM 中存在”作为已可乘车的证明。
4. 按相同来源核对 1、2、10 号线。本轮北京地铁 2 号线官网页面读取超时，未使用旧新闻代替现行表，也未改其数据。
5. 获取各时段实际发车间隔及真实观测误差样本。首末班准确不代表全天逐班到站准确；本轮没有实测误差下降百分比，不能承诺秒级准确。

## 用户校准更新（2026-09-18）

后续已实现秒级现场记录、确认班次后固定匹配、历史加权学习与衰减锚点融合、冻结预测误差比较，以及跨线路记录累积。验证结果只有达到样本量和覆盖天数要求后才提高历史修正权重。连续班次间隔学习已实现，规则见 `docs/headway-learning.md`。算法测试不能替代现场准确度验证，完整校准规则见 `docs/user-calibration.md`。

现已增加工作日/周末、早高峰/平峰/晚高峰分组，以及两小时现场到站锚点。基础预计保持不变；用户可选择系统预计或用户校准作为主倒计时，后者无适用样本时明确回退。完整规则、回退顺序和兼容方式见 `docs/user-calibration.md`。
