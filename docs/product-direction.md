# 产品方向与功能分层

Metro Nearby 的核心定位调整为“离线地铁位置与换乘助手”。

## 默认主线

1. 使用设备定位展示最近车站和多个附近备选站；
2. 明确距离是站点中心之间的直线距离，不伪装成步行导航；
3. 展示本站线路、城市标签和换乘关系；
4. 基于离线站序规划少换乘或少经过站路线；
5. 订阅用于保存常用站、通勤线路和方向；
6. 线网图、搜索、城市分组和自定义线路继续作为核心能力。

这些功能只依赖位置、站点和线网拓扑，能够在没有网络和运营方实时接口时稳定工作。

## 实验功能

预计班次、用户校准、发车间隔学习、班次表和区间车继续保留，但不再作为默认首页主线：

- “显示预计班次”首次安装及没有旧设置时默认关闭；
- 开启后仍明确标记为离线预计；
- 班次表管理放在设置页“实验功能”中；
- 用户自行维护的数据仍保持原有优先级和本地持久化；
- 不用拟合结果或内部误差宣称真实到站准确率。

## 后续边界

路线规划基于静态线网，不感知临时封站、甩站、施工、客流控制或实时运营调整。若将来获得可靠的官方动态来源，应作为独立数据层接入，不改变离线功能的可用性。
