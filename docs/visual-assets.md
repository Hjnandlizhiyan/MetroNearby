# 吉祥物与空状态插画

落地日期：2026-09-19。

## 素材

所有图片均为透明 PNG，放在 `app/src/main/res/drawable-nodpi/`，由 Compose 以明确的 `dp` 尺寸缩放：

| 文件 | 用途 |
| --- | --- |
| `mascot_metro_conductor.png` | Metro Nearby 完整吉祥物，设置页品牌卡片、正常站点标题、非空订阅标题 |
| `empty_location.png` | 未授权定位、定位失败 |
| `empty_subscriptions.png` | 我的订阅为空 |
| `empty_no_service.png` | 当前方向没有后续班次、今日已收车 |
| `location_status.png` | 最近站页“当前定位”状态卡，表示定位成功、精度与更新时间 |
| `calibration_guide.png` | “记录实际到站时间”弹窗的三步校准引导 |
| `loading_train.png` | 定位和线路数据加载动画中的列车精灵，也显示在首页最近站标题右侧 |
| `radar_conductor.png` | 附近站雷达页右上角的列车长，手持雷达并指向附近站信号 |

吉祥物沿用应用图标中的短深蓝发、蓝色眼睛、深蓝乘务帽、青色帽带、白蓝制服与珊瑚色点缀。空状态只增加与场景直接相关的道具，不在图片中放文字，文案仍由 Compose 渲染，方便无障碍、主题适配和后续修改。正常有数据时，完整吉祥物以 76dp 的轻量尺寸出现在站点标题和订阅标题右侧，避免角色只在空状态出现。

## 生成口径

素材使用内置图像生成工具创建，以现有 `ic_splash_icon.png` 为角色参考。共用要求是：简洁二次元 Q 版、圆润清晰轮廓、少量赛璐璐阴影、深蓝/青/白主色、透明背景、无文字、无水印。

场景变化：

- 吉祥物：完整站姿，一手挥手，一手持交通卡；
- 定位失败：用放大镜寻找简化定位标记，表情保持轻松；二次修订时放大画面右侧眼睛并统一双眼透视、瞳孔和高光；
- 暂无订阅：手持书签卡，指向心形车站标记；
- 暂无班次：与小型地铁车头坐在一起，手持无数字时钟，搭配月亮与星星。
- 定位状态：吉祥物拿手机站在青色定位标记旁，带雷达环；
- 校准引导：由虚线时钟、现场到站按钮、定位锚点和清晰时钟组成从左到右的流程；
- 加载列车：吉祥物从正面列车驾驶窗挥手，由 Compose 在轨道上往返和轻微上下浮动。
- 雷达列车长：同一角色手持青色圆形雷达并指向信号，透明背景，小尺寸显示在雷达页右上角。

原始生成图保留在 Codex 的生成图片目录；工程内版本按实际展示场景缩放到 512–1200 像素长边，以控制 APK 体积并保留透明通道。设置入口的齿轮、加载轨道与站点圆点由 Compose Canvas 绘制，不新增 material-icons 或动画依赖。
