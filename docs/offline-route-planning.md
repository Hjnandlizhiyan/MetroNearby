# 离线路线规划

核心逻辑位于 `domain/OfflineRoutePlanner.kt`，界面位于 `ui/RoutePlannerScreen.kt`。

## 图模型

- 节点使用“城市 + 规范化站名”，同城市同名站自动合并为换乘节点；
- 不同城市的同名站不会连接；
- 边来自每条线路的 `segments`，规划时按可双向乘坐处理；
- 每条边保留线路 id、线路名和主题色；
- 自定义线路只要带有有效站点与相邻区间，也会参与规划。

## 路线偏好

- 少换乘：先比较换乘次数，再比较经过站数；
- 少经过站：先比较经过站数，再比较换乘次数。

结果按连续线路合并为乘车段，显示上车站、下一站方向、本段下车站、站数和换乘站。它不使用发车时刻、用户锚点或实时数据。

## 限制

- 暂不规划跨城市路线；
- 不感知封站、临时甩站、施工和单向运营；
- 当前按相邻站关系处理，没有步行换乘距离和无障碍路径权重；
- 路线只代表静态线网可达关系。
