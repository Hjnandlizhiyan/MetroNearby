# 常用站、通勤方向与站点订阅

2026-09-18 用户确定口径：订阅即关注，主页集中查看多个站点，每站可指定通勤线路和方向。保持全离线，不涉及后台提醒。

## 使用方式

- 在“附近 / 选站”搜索车站，点击“订阅本站”，选择线路和方向后保存。
- 可以关注全部线路，也可以仅关注某条线路的全部方向或一个通勤方向。
- “我的订阅”集中显示各站每个已选方向的下一班预计到站，并遵循主页选择的“系统预计 / 用户校准”口径；“查看全站”进入完整班次与用户观测页面。
- “编辑”修改通勤偏好，“取消订阅”移除该站；设置页也提供管理入口。
- 有订阅时重新启动默认打开“我的订阅”。订阅列表无需定位权限。

## 数据与维护

- 常用站与订阅共用一份列表，每个物理站一项；沿用 TransferStationResolver 的站名归一化规则。
- StationSubscription 保存 stationName、lineId、directionId。null 线路表示全部线路，null 方向表示全部方向。
- SharedPreferences 的 metro_settings / station_subscriptions 保存 JSON；不修改内置线路或 user_overrides.json。
- StationSubscriptions 承担去重、配置校验、方向筛选与预览逻辑。ArrivalEstimator.boardingDirections 与推算共用可乘交路判定，不依赖当前是否运营；禁用交路不产生预计班次。
- 收车后保留订阅，按所选方向的服务窗口展示首班提示。数据更新导致站点、线路或方向失效时，保留配置并提示编辑，不擅自显示其他方向。
- 方向预览保留现有区间车和停站窗规则；仍不对区间车与全程车去重。订阅卡片按当前口径显示一条主倒计时；用户口径无适用样本时明确回退到系统预计。

## 验证

新增 27 个 JVM 用例，覆盖持久化往返、重复订阅、站名后缀、换乘线路筛选、方向筛选、失效引用、首末班、终点站、环线区间车和禁用交路等。全量 228 个用例通过，debug 构建通过。

模拟器验证添加西直门（2 号线内环）与南锣鼓巷（6 号线开往潞阳）、集中展示、重启保留、设置管理入口、修改方向、查看全站和取消订阅。测试后恢复原设置与输入法，用户观测文件保持原样。
