# 常用站收藏与通勤偏好

2026-09-25：按离线随身助手的第二阶段规划升级。订阅即收藏，不含后台提醒；旧预计班次界面已移除。

## 使用方式

- 首页搜索车站后点击“收藏本站”，或在底部“收藏”编辑已有站点。
- 每站可保存通勤线路、方向，以及家、公司、学校、常去标签。
- 选择一个同城市的“常用目的地车站”。收藏卡上的“去常用目的地”以收藏站为起点打开路线，默认少换乘，可在路线页调整；通勤线路和方向只是记录，不强制约束路线。
- “常走出口”最多80字，“收藏备注”最多500字，选填。它们是个人记录，不代表出口实时开放情况。
- “查看全站”打开该站首页；“出入口与设施”查看资料及独立的车站备注。
- 收藏备注与设施页面的出口、设施、换乘备注分别保存，不相互覆盖。
- 编辑后保存生效；取消不修改。可清除目的地、标签或文字，也可取消整站收藏。
- 卡片保留8dp线路色条，换乘站显示多条线路色。

## 数据与兼容

- SharedPreferences：metro_settings / station_subscriptions，使用原有列表，不触碰历史时刻数据。
- StationSubscription 保留 stationName / lineId / directionId，新增带默认值的 tag / destinationKey / preferredExit / note。
- 旧数据直接兼容；更新保持列表顺序与通勤方向，文本保存时去除首尾空白。
- 目的地使用 OfflineRoutePlanner 的城市+站名稳定键。只允许同城市不同站；失效引用保留并提示重新选择或清除，不自动替换。
- 同名站存在于多个城市且未选线路时，不猜测路线起点，需要先指定通勤线路。
- 收藏本身仍沿用旧站名归一化身份，同名跨城市的独立收藏属于后续站名工具升级范围。
- 附加信息校验位于 domain/SubscriptionPreferences.kt，不改变历史预测领域代码的有效性口径。
- 纯离线、零新增依赖，不请求后台权限。
